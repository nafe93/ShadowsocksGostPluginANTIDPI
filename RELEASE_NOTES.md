# GOST + AntiDPI for Shadowsocks Android

Нативный Android-плагин GOST со встроенным ByeDPI 17.3.

- Стратегии: aggressive, balanced, compat, disorder, fake, oob, tlsrec и off.
- Без Python, root и отдельного приложения ByeDPI.
- Отдельные APK для arm64-v8a, armeabi-v7a, x86 и x86_64.
- Плагин можно установить рядом с исходным Shadowsocks GOST Plugin.

Для большинства современных телефонов выберите APK `arm64-v8a`.
Минимальная версия — Android 8.0. После установки выберите GOST + AntiDPI
в Shadowsocks, настройте сервер и включите нужную стратегию вместо off.
При включённом AntiDPI используйте цепочку `-F` и пустой `config.yaml`.

Эта сборка подписана debug-ключом. Для обновления поверх неё следующую
сборку нужно подписывать тем же ключом; переход на другой ключ потребует
переустановки плагина. Для постоянных релизов рекомендуется отдельный
сохранённый release-ключ, который нельзя добавлять в Git.

Проверены сборка всех архитектур, аргументы стратегий, запуск SOCKS5,
HTTP-передача и остановка дочернего процесса. Пользователь подтвердил
работу Android-сборки на своём устройстве.
